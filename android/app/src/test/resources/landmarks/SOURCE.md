# Where this shard comes from

`G3RJ.json` is the landmark archive's shard for the cell around Toronto, as
gridpointcode.com served it on 1 October 2026 from the archive built on
27 September 2026. The archive is built from [GeoNames](https://www.geonames.org)
by `web/scripts/build-landmarks.mjs`, and GeoNames' data is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The screens drawn for the design's reference images find it where the app keeps
the shards it met while looking around, so the landmark section shows the real
places near each code with no connection to the site.
